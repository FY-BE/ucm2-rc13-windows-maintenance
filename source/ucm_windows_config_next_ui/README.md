# UCM Config Studio Next UI

这是 Qt6/QML 产品前端，唯一 WinUSB 后端位于本工程的 `backend` 目录。revision 9 保持外部消息合同，正式结果由 ARM 计算。工程师登录、设备实时能力与主机控制权分别校验；当前 A001 候选仍需真实 USB 日志和整机验收。

## 使用与权限

- 普通启动连接唯一符合合同的设备；握手、重连、日志、产品配置事务和升级分块在后台 worker 串行操作。断连按 1/2/5 秒重试，点击信息页“断开设备”后停止重试。
- `--offline` 用于离线预览；`--screenshot` 和全部 `*self-test` 参数也自动强制离线。此模式禁用自动与手动USB连接，不操作实物。
- 客户基础草稿默认 DE168、总长2500、B段90、D段90、E段40、杆径90 mm。图示与现场坐标映射尚未核实；草稿不因连接或配置轮询被覆盖，也不自动保存或应用。
- 当前运行配置与开机配置分别从ARM读取，不能把本地草稿显示成已生效。客户只有基础字段应用和“保存ARM当前配置为开机配置”入口；两者各需确认，当前操作授权、active能力或实时控制状态不足时禁用，离线模式始终禁止写入。
- 工程师产品配置页提供完整型号/输入策略JSON、暂定phi_B/phi_D=0.46的草稿编辑、ARM校验、应用、开机保存。identity按ARM canonical算法生成，只是事务身份，不表示通过ARM校验或完成标定。
- 升级仅工程师操作：选择包与版本/型号/Build ID，确认传输后分块上传，校验并暂存，再单独确认激活；提供状态查询与中止。ARM 必须处于主机托管且硬件安全状态。主机每秒续租；失联超过五秒后 ARM 安全停机，成功则重新训练并恢复自主模式，失败则保持故障安全态。结果未知时不自动重发或激活。本轮允许无签名候选包，正式 USB 身份与发布签名不在范围内。

## 监测与导出

客户与工程师界面共用浅灰背景、白色圆角卡片和克制的蓝色交互色。Windows 中文统一使用系统自带的 Microsoft YaHei UI，避免 Qt/DirectWrite 对可变 CJK 字体的小字号和弹窗渲染异常；主要数值采用 Segoe UI Variable Display。客户首页保留原有设备线稿，四杆颜色仅用于对应标识与趋势线。离线预览明确显示等待设备数据，不生成模拟曲线。

监测调度目标为50 Hz（20 ms），这是客户端目标，不是实测吞吐或延迟承诺；忙时跳过轮询，不积压补发。Windows显示ARM结果，不计算正式总力、单杆力或应变。消息30与45按publisher/session/sequence/frame/capture-request/time六项配对；无效或过期结果显示不可用。30未提供NCC/T0/AFE与单杆原因时这些字段留空，不伪造零。PLC输入状态不能冒充ARM过程状态。产品波形能力未激活时不发出波形请求。

实时趋势只对连续有效的原始点做不越界的曲线插值，指针读数和 CSV 仍取原始样本，失效区间保持断线。原始 2048 点波形不做数值滤波；波形与趋势的光标独立于主曲线绘制，移动光标时不重绘整张采样图。

CSV保留最近最多6000条记录，含六项ARM身份、观察时间、正式/杆有效掩码、ARM原因与明确N单位；所有64位身份直接输出十进制字符串。重复身份不追加，断连及无效区间写gap行，无效数值为空。客户与工程师均可从信息页导出。

产品诊断包在后台读取产品状态、原始能力、设备日志目录和原始日志，每个调度轮只读一个分块。文件身份/offset/尺寸变化会丢弃该文件片段；可变日志标为快照。包内包含manifest、SHA256清单、CSV、读错误清单。部分读取失败会保存`READS_INCOMPLETE`并明确显示不完整；不把完成文件写入等同于完成设备采集。断连取消未校验的导出。

revision 2 旧工程资料只归档，不进入产品构建或作为 revision 9 的验收证据。

## 本地构建与验证

在项目配置好的Qt6/CMake构建环境中构建本目录，启用`BUILD_TESTING`运行针对性CTest。截图只能使用`--screenshot`或`--offline`。现有测试覆盖协议golden、worker配置缓存与断连清空、重连退避、产品波形禁用、正式应变不可由Windows推算；新增产品事务与日志测试随本轮集成执行，未执行项不能宣称通过。

离板测试不授予真机验收信用。真实配置、控制切换与升级需核对设备实时安全状态、操作回执及重启后的状态；当前 A001 板卡以候选身份单独记录。

C392 / ARM 391：标准力标定页可独立回读当前运行和开机配置，显示 Kmat、四路耦合偏置与全部分段修正节点；应用/保存后自动回读。候选使用 candidate/v3，不把拟合诊断截距重复写入耦合偏置。真 USB 写入与恢复验证通过，计量精度仍需标准力现场验收。

GW1850R 的结构换算、标准力标定、人工维护权限和下发/回读顺序冻结在 [`GW1850R_CALIBRATION_AUTHORITY_V1.md`](GW1850R_CALIBRATION_AUTHORITY_V1.md)。Windows 只允许修改 Kmat、四路相对坐标残余偏置和零锚定单调 PWL；5230/280/250 mm、模厚 1:1、H=288 mm 与 eta=0.35 均只读。
